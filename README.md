## 💡 메일딸깍은 이런 프로그램입니다

월말마다 이런 작업을 반복하고 있지 않나요?

```text
Excel 매출자료 확인
        ↓
거래처별 마감자료 생성
        ↓
담당자 확인
        ↓
메일 작성
        ↓
파일 첨부
        ↓
발송
        ↓
발송 여부 다시 확인
```

메일딸깍은 이렇게 흩어져 있던 작업을

```text
데이터 업로드
      ↓
검증
      ↓
마감자료 생성
      ↓
수신자 · 금액 · 첨부 확인
      ↓
메일 발송
      ↓
발송 이력 저장
```

하나의 업무 흐름으로 연결합니다.

# ✨ 주요 기능

### 📊 Excel 데이터 관리

- 매출 데이터 업로드
- 필수 데이터 누락 확인
- 금액 및 데이터 검증
- 거래처별 데이터 관리

### 📄 마감자료 생성

- 거래처별 Excel/PDF 마감자료 생성
- 업체별 마감 상태 확인
- 담당자 및 연락처 관리
- 마감자료 발송 여부 확인

### ✉️ 메일 발송

- 거래처 담당자별 메일 발송
- 첨부파일 자동 연결
- 발송 전 수신자 · 금액 · 첨부파일 최종 확인
- 상황에 따른 메일 템플릿 사용
- 발송 결과 및 이력 저장

### 🧾 세금계산서 확인

- 세금계산서 Excel 데이터 비교
- 미발행 업체 확인
- 금액 불일치 확인
- 확인이 필요한 거래처에 메일 발송

### 🔐 로컬 중심 데이터 관리

업무 데이터는 사용자의 PC를 중심으로 관리하도록 설계했습니다.

ERP를 대체하는 프로그램이 아니라  
**기존 업무를 더 빠르고 편하게 처리하기 위한 보조 도구**입니다.

# 📧 메일 연동

메일딸깍에서는 사용 중인 메일 계정을 연결하여 거래처에 직접 메일을 발송할 수 있습니다.

지원 대상으로 설계된 메일 환경:

- Gmail
- Naver Mail
- Outlook
- 회사 SMTP

일부 메일 서비스에서는 일반 로그인 비밀번호 대신  
**앱 비밀번호(App Password)** 설정이 필요할 수 있습니다.
